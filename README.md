# Study Planner

Навчальний планувальник на React, TypeScript і Vite. Для стилізації використовується Tailwind CSS 4 через Vite-плагін; CSS-змінні в `src/index.css` забезпечують світлу й темну теми.

## Можливості

- Додавання завдань із назвою, описом, категорією та пріоритетом.
- Позначення завдань виконаними та видалення завдань.
- Фільтрування за статусом і категорією.
- Сортування за пріоритетом; виконані завдання відображаються внизу списку.
- Скидання всіх фільтрів із помітним індикатором, коли фільтри активні.
- Перегляд статистики завдань і перемикання теми.

## Запуск

Потрібен Node.js із npm.

```bash
npm install
npm run dev
```

## Перевірки

```bash
npm run build
npm run lint
```
