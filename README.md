# Study Planner

Навчальний планувальник на React, TypeScript і Vite. Інтерфейс стилізовано за допомогою Tailwind CSS 4; Tailwind підключено через Vite-плагін, а змінні кольорів у `src/index.css` забезпечують світлу й темну теми.

## Запуск

```bash
npm install
npm run dev
```

## Перевірки

```bash
npm run build
npm run lint
```
