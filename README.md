# Study Planner

Навчальний планувальник на React 19, TypeScript і Vite. Маршрутизація реалізована в Declarative Mode React Router 8. Інтерфейс стилізовано за допомогою SCSS та BEM-патерну; доступні світла й темна теми.

## Можливості

- Додавання завдань із назвою, описом, категорією та пріоритетом.
- Позначення завдань виконаними та видалення завдань.
- Фільтрування за статусом і категорією.
- Сортування за пріоритетом; виконані завдання відображаються внизу списку.
- Скидання всіх фільтрів із помітним індикатором, коли фільтри активні.
- Перегляд статистики завдань і перемикання теми.

## Запуск

Потрібен Node.js 22.22 або новішої версії та npm.

```bash
npm install
npm run dev
```

## Перевірки

```bash
npm run build
npm run lint
```
